# BusGo – Bus Ticket Reservation System

## Project Overview
BusGo is a web-based Bus Ticket Reservation System developed using Java and Spring Boot. It provides a platform for passengers to search available bus trips and manage reservations, while administrators can manage buses, routes and trip schedules.

## Features
- Bus search based on source, destination and journey date.
- Trip and seat availability management.
- Passenger booking functionality.
- Booking and payment processing.
- Separate user and administrator interfaces.
- Admin management of buses, routes and trips.
- Database integration and REST API support.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate ORM
- MySQL (if used in the final implementation)
- HTML, CSS and JavaScript (if used in the frontend)
- Maven
- Postman

## Project Architecture
The application follows a layered architecture:
- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Configure the database connection.
4. Build the project using Maven.
5. Run the Spring Boot main application class.
6. Open the application at http://localhost:8080/.

## Project Purpose
Developed as an Advanced Java Programming academic project to demonstrate Java web development, REST APIs, database management and online reservation functionality.
